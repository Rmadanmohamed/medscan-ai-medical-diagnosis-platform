MedScan AI Project Documentation

MedScan AI is an educational Streamlit prototype for presenting medical AI interface ideas. It is not a validated clinical system.

This project is for educational and portfolio demonstration only. It is not a medical diagnosis tool and should not be used for clinical decisions.

Current Scope

  • Medical image workflow demo
  • Retinal image workflow demo
  • Tabular risk-screening workflow demo
  • Modular analyzer files retained for experimentation

Current Limitations

  • No independently verified clinical performance metric is claimed.
  • No clinical dataset is bundled.
  • No production-ready trained medical model is bundled.
  • Demo outputs must not be interpreted as medical advice.

How to Run

Install dependencies, then run streamlit run app.py.
